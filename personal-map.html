To begin, load a Teyvat map image that you have permission to use. For detailed zoom, a high-resolution image or a licensed tile set is required. This is a personal map workspace, not an imported chest database.

Advanced: high-resolution tiled map

Use a tile set you own or are licensed to use, hosted on your own GitHub Pages or another server permitting reuse. URL must contain {z}, {x}, and {y}.

Tiles need standard Leaflet XYZ coordinates. This is for compatible map tile sets, not arbitrary image links.

You can zoom beyond the source image resolution, but extreme zoom will be pixelated unless high-resolution tiles are installed.

The image is stored on this device using browser storage; large files may exceed storage limits. For sharp extreme zoom, tiled artwork is better than a single image.
